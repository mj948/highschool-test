# 고교선택 적성검사 v2 — 핸드오프 패키지

이 폴더는 **클로드 코드(또는 다른 새 환경)로 작업을 이관할 때** 기획·문항·가중치·디자인 결정이 단 하나도 유실되지 않도록 만든 완전한 스냅샷입니다.

## 📦 파일 목록 (8개)

| # | 파일 | 역할 | 우선순위 |
|---|---|---|---|
| 1 | **`CLAUDE_CODE_시작.md`** | 클로드 코드에 처음 줄 메시지 + 작업 패턴 | **여기부터 시작** |

## 🎯 사용법

### 클로드 코드로 작업 이관할 때

1. 작업할 폴더에 이 폴더 전체를 `handoff/`로 복사
2. 클로드 코드 실행
3. `CLAUDE_CODE_시작.md` 의 §A 첫 메시지 프롬프트를 그대로 복사
4. 클로드 코드에 첫 메시지로 붙여넣기
5. 클로드 코드가 4개 핵심 파일을 정독하고 검증 답변을 줄 때까지 기다림
6. 답변이 정확하면 §B의 작업 의뢰 패턴으로 새 기능을 요청

### 다른 사람·다른 LLM에게 인수인계할 때

1. 이 폴더 전체를 zip으로 묶어 전달
2. `CLAUDE_CODE_시작.md` 와 `SPEC.md` 를 먼저 읽도록 안내
3. 검수 질문(§A 첫 메시지에 있는 6개 항목)으로 정독 여부 확인

### 직접 사용할 때 (개발 없이 운영만)

1. `index.html` 을 [Netlify Drop](https://app.netlify.com/drop) 에 끌어다 놓기 → 배포 완료
2. 응답자가 많아져 클라우드가 필요해지면 `SUPABASE_설정가이드.md` 따라 6단계 진행

## ⚠️ 절대 원칙

새 구현이 다음을 위반하면 **회귀(regression)**입니다:

1. `QUESTIONS.json` 의 39개 문항 텍스트를 한 글자라도 수정
2. `WEIGHTS.json` 의 모든 숫자값을 (별도 의뢰 없이) 수정
3. "세특", "학종", "비교과", "교과/지역균형 전형" 같은 고교 전문용어 사용
4. 멘탈 약(N<50)인 학생에게 자사고/외고/국제고/과학고/영재학교 1순위 추천
5. `SPEC.md §10` 의 11개 검증 시나리오 중 하나라도 결과가 다르게 나옴

위 5개는 단순 기능 차원이 아니라 **사용자 안전 + 신뢰성** 차원의 요구사항입니다.
