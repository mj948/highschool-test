# 고교선택검사 v3.1

한국 중·고교 학부모용 고교 선택 보조 검사. 초등 3학년부터 중학교 3학년까지.

## 이 검사가 하는 일

학부모가 결과를 읽고 세 가지를 알게 한다.

1. 우리 아이는 어떤 조건에서 공부가 잘 유지되는가
2. 어떤 학교 환경에서는 문제가 생길 가능성이 있는가
3. 학교를 실제로 비교할 때 무엇을 확인해야 하는가

**안 하는 것.** 예상 내신 등급, 적합도 점수, 심리 유형 이름 붙이기, 초등생에게 고교 유형 순위 주기.

## 파일

| 파일 | 역할 |
|---|---|
| `SPEC.md` | 마스터 스펙. **여기부터 읽는다** |
| `QUESTIONS.json` | 화면에 노출되는 문항 |
| `RULES.json` | 판정 로직 |
| `index.html` | 위 셋의 구현 (단일 파일) |
| `tests/` | 시나리오·불변식 테스트 |
| `SUPABASE_설정가이드.md` | 클라우드 설정 |
| `_archive_v2/` | **폐기된 v2.1 문서.** 과거 응답 열람 참조용 |

## 단일 진실 공급원

`SPEC.md` → `QUESTIONS.json` → `RULES.json` → `index.html` 순으로 맞춘다.

> v2.1의 **"문항 한 글자도 수정 금지"**와 **"충돌 시 index.html이 정답"** 원칙은 폐기했다.
> 문항은 타당성이 우선이고, 코드는 스펙을 따른다.

## 문항 수

중2·중3 핵심 31문항, 초등 27문항. 선택입력 2, 조건부 3.
보호자 25 · 아이 10.

## 고치는 법

`index.html`은 **생성물이다.** 직접 고치지 않는다.

```
_build/css.txt  engine.js  ui.js  screens.js  store.js   ← 여기를 고치고
node _build/build.mjs                                     ← 다시 만든다
```

문항과 판정은 `QUESTIONS.json`·`RULES.json`을 고친 뒤 같은 명령으로 반영한다.

## 테스트

```
node tests/run.mjs
```

시나리오 20개 + 불변식 15개. 하나라도 실패하면 배포하지 않는다.

## 배포

`index.html` 한 파일을 Netlify Drop에 올리면 끝난다.
응답 저장이 필요하면 `SUPABASE_설정가이드.md`를 따른다.
